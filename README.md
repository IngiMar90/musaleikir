# Músaleikir

Þrír einfaldir músarleikir á íslensku fyrir nemendur sem eru að læra að nota tölvumús.

- Stjörnur: færa músina á stór skotmörk.
- Blöðrur: miða og smella.
- Dýravinir: halda inni, draga og sleppa.

Engin innskráning, tímamörk, auglýsingar eða söfnun persónuupplýsinga. Stillingar eru aðeins vistaðar í vafranum.

## Keyra

Opnaðu `dist/index.html` í vafra eða þjónaðu `dist/` með einföldum vefþjóni. Engar uppsetningar eða ytri gagnatengingar þarf.

## Aðgengi

Stór skotmörk, þrjú erfiðleikastig, stillanleg lotulengd, hljóð valfrjálst og sýnikennsla. Virkar með mús, snertifleti og snertiskjá. Hægt er að minnka hreyfingar með kerfisstillingu. Lyklaborð getur einnig stýrt hnöppum og valið mat og dýr með Enter/bilslá.
